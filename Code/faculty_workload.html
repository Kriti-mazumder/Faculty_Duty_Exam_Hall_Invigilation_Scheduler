SQL Calculation Schema & Quota Mapping

Invigilation metrics are synthesized in real-time from the institutional assignment table. Standard university policy specifies a baseline ceiling of 5 duty assignments per exam session. 

SELECT 
    f.faculty_id,
    f.faculty_name,
    d.dept_code,
    f.designation,
    COUNT(a.assignment_id) AS total_duties,
    SUM(CASE WHEN a.assignment_status = 'COMPLETED' THEN 1 ELSE 0 END) AS completed_duties,
    SUM(CASE WHEN a.assignment_status = 'SCHEDULED' THEN 1 ELSE 0 END) AS upcoming_duties
FROM FACULTY f
INNER JOIN DEPARTMENT d ON f.dept_id = d.dept_id
LEFT JOIN INVIGILATION_ASSIGNMENT a 
    ON f.faculty_id = a.faculty_id 
    AND a.exam_session_id = 'TERM_2025_SP_MID'
GROUP BY f.faculty_id, f.faculty_name, d.dept_code, f.designation
ORDER BY total_duties DESC;

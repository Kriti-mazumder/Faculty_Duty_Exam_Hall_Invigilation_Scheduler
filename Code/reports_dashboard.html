Backend Query Architecture & Foreign Key Joins MySQL 8.0 Engine

Statements are generated via relational joins across FACULTY, DEPARTMENT, INVIGILATION_ASSIGNMENT, EXAM, and ROOM.

SELECT f.faculty_id, f.full_name, d.dept_name, COUNT(ia.assignment_id) AS total_duties, SUM(CASE WHEN e.exam_status = 'COMPLETED' THEN 1 ELSE 0 END) AS duties_completed FROM FACULTY f INNER JOIN DEPARTMENT d ON f.department_id = d.department_id LEFT JOIN INVIGILATION_ASSIGNMENT ia ON f.faculty_id = ia.faculty_id LEFT JOIN EXAM e ON ia.exam_id = e.exam_id WHERE e.term_code = 'SP25_MID' GROUP BY f.faculty_id;
